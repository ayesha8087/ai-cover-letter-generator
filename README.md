# ✉️ AI Cover Letter Generator

An AI-powered web application that generates professional cover letters based on user resume and job description inputs.

Built using Python and Streamlit, this tool helps job seekers quickly create personalized cover letters for applications.

---

## 🚀 Features

👤 User-friendly input form  
💼 Job role customization  
📄 Resume input support  
📝 Job description analysis  
✉️ AI-style cover letter generation  
📥 Download cover letter as text file  
⚡ Simple and fast Streamlit interface  

---

## 🏗️ Tech Stack

- Python 🐍  
- Streamlit 🎈  

---

## 🧠 How It Works

1. User enters name and job role  
2. Provides resume and job description  
3. App processes inputs  
4. Generates a personalized cover letter  
5. User can download the final output
